# lccbyg-docs

Jeg har lagt en prøveside ind i 3.2/da mappen: https://github.com/LccBuild/lccbyg-docs/blob/main/docs/3.2/da/index.md

Html præsentationen af ”Pages” er her: https://lccbuild.github.io/lccbyg-docs/
Det er den slutbrugerne vil se.
Hvis Pdf generation virker, skal vi kikke på at få et bedre tema på html siderne.

Altså kilde : https://github.com/LccBuild/lccbyg-docs/blob/main/docs/3.2/da/index.md

Visning:  https://lccbuild.github.io/lccbyg-docs/3.2/da/


Billederne er pt. linket fra lccbyg.dk, men det er ikke en holdbar løsning, de skal fremover gemmes i mapper ( inde i docs) hvis vi vælger denne løsning.
Billederne vil altså måske drille, hvis du ikke flytter dem til en Github mappe.


Det er tanken at hjælpen versioneres, således at der ligger komplette sæt af sider og undersider i versionerede mapper, ligesom vi gør pt. 
Vores nuværende danske hjælpefil , f,eks.( https://lccbyg.dk/help/32/ ) , ville altså skulle bo i : lccbyg-docs/docs/3.2/da/ mappen.
